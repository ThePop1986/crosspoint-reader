# PiccoOS kit — changelog

## v4 — 2026-11-12 (по логам первого CI, commit c6372a68)
**Причина сбоя `simulator`:** в скриптах ввода время шага трактовалось как задержка, а в симуляторе оно абсолютное внутри сегмента (сегмент начинается после каждого `WAIT`; события сортируются по времени — README «Automated QA», `HalGPIO.cpp`). Поэтому `500:QUIT` срабатывал раньше `1500:SHOT`, а `TAP` в Library стоял после блокирующего `0:WAIT`. Прошивка и симулятор не менялись.
- Сценарии переписаны с абсолютными временами. Library: основной путь — кнопки `DOWN` → `ENTER` (`library`); путь касанием — отдельный экспериментальный `library_tap` с координатой `(0.50, 0.5225)` из параллельного патча ChatGPT Work (центр строки Library по метрикам Lyra: 386…450 px).
- `<сценарий>.timeline.txt` — разобранный скрипт (сегмент, время, шаг) для каждого сценария (идея из патча Work).
- `lint_script`: сценарий с убывающим временем в сегменте, шагом после `QUIT` или без `QUIT` не запускается.
- Новая проверка: в логе должна быть строка `[SIM] Saved screenshot: <путь>` (различает «SHOT не выполнен» и «кадр пустой»).
- Размер кадра проверяется: 480×800. Разные размеры больше не считаются «различием 100%» в `cover_grid_differs` (SKIP + ошибка по кадру).
- Кадры удаляются до проверки таймаута — пропущенный сценарий не оставляет старых изображений.
- Описание таймаута исправлено: бюджет для сценариев, внешний жёсткий лимит — `timeout-minutes` шага CI.
- `platform = native@1.2.1` (версия из первого CI); `penv-freeze.txt` через `uv pip freeze` (в penv нет `pip`).

## v3 — 2026-11-12 (второе ревью)
- **CI: ошибки больше не маскируются `tee`.** `defaults.run.shell: bash` на уровне workflow (GitHub запускает `bash -eo pipefail`; по умолчанию было `bash -e` без `pipefail`) + `set -euo pipefail` в шаге `pins`. Исправляет неверное утверждение из v2.
- CI: `mkdir -p sim-out` перед записью окружения — артефакт появится, даже если упала установка зависимостей.
- `capture_screens.sh`: ожидаемые кадры (`.bmp` и `.png`) удаляются перед сценарием — старый скриншот не может пройти проверку.
- `capture_screens.sh`: `RUN_TIMEOUT_S` теперь жёсткий: сценарий получает min(лимит сценария, остаток времени); превышение — не более ~3 с на завершение процесса.
- `capture_screens.sh`: новая обязательная проверка `cover_grid_differs` — `home_cover_grid` должен отличаться от `home_lyra` (≥ 5% пикселей). Это не доказывает, что включился именно COVER_GRID: первый скриншот проверить глазами.
- Actions: в комментариях точные релизные теги (`v6.1.0`, …). `verify_pins.sh` проваливает проверку только при несовпадении точного тега; сдвиг основного тега (`v6`) — `INFO`.

## v2 — 2026-11-12 (исправления по внешнему ревью)
**CI (`piccoos-ci.yml`)**
- Push-триггер: `piccoos-dev` (+ `piccoos/**`).
- Логи сборки и запись окружения (`pip freeze`, penv freeze, `pio pkg list`, submodules, commit) загружаются **всегда**, в т.ч. при ошибке.
- `firmware.bin` **не публикуется по умолчанию**; только `workflow_dispatch` + `publish_firmware=true`, комплектом с `LICENSE`, `licenses/`, `PINS.md`, `SOURCE.txt`, срок хранения 7 дней.
- epubcheck скачивается с проверкой sha256.
- Job `pins` запускает `tools/verify_pins.sh` (SHA actions против тегов; существование upstream/SDK/simulator коммитов).
- Сценарии симулятора: лимит 15 минут на шаг, итоги в Job Summary.
- Python-зависимости больше не обновляются с `-U`.

**`sim/capture_screens.sh`**
- Путь к симулятору переводится в абсолютный до смены каталога (была ошибка запуска в CI).
- Обязательные сценарии (`home_lyra`, `home_cover_grid`) проверяют: код выхода, Home в логе, наличие, ненулевой размер и «непустоту» скриншота.
- `library` — экспериментальный, не роняет запуск.
- Таймаут на сценарий и на весь запуск (переносимый, без GNU `timeout`); `summary.txt`.

**Корпус**
- Встроенные шрифты DejaVu Serif (+ лицензия): вывод не зависит от системных шрифтов; при отсутствии шрифта — ошибка, а не тихая потеря надписей.
- Английские книги получают английский текст глав.
- `manifest.json` записывает Python, Pillow, платформу и sha256 шрифтов.
- Требование Python 3.10+ (Pillow 12).
- `LICENSE-CORPUS.md` (CC0 + исключение для шрифтов).
- `pack_corpus.py`: ZIP с UTF-8-флагом и проверкой имён/sha256 против манифеста.

**Документы**
- macOS-инструкция переписана под `ThePop1986/crosspoint-reader`, ветка `piccoos-dev`; убран `rm -rf fs_/books` — тестовая «SD-карта» в отдельной папке `piccoos-sd`.
- `PINS.md`: честные границы воспроизводимости («прослеживаемые», не «воспроизводимые» сборки).
- `LICENSE_AUDIT.md`: постоянные ссылки на файлы лицензий; уточнено значение «Confirmed».
- Simulator ini: `ricmoo/QRCode @ 0.0.1` вместо `^0.0.1`.
