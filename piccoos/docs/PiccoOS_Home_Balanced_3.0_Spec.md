## 2. Решения

### D-029 Миниатюры: две высоты — 300 и 192
- Confirmed: `Epub::generateThumbBmp(h)` создаёт `thumb_<h>.bmp`. 1-bit; `JpegToBmpConverter` с `crop=true` масштабирует источник по **большему** коэффициенту под бокс `0.6h × h` и сохраняет изображение **целиком** (600×900 при h=300 → BMP 200×300). Обрезка — только при отрисовке: `BaseTheme::drawCoverThumbFill` рисует 1:1, по центру, с clip по слоту.
- `thumb_300` — текущая книга; `thumb_192` — недавние. Без текущей книги (C-1) все миниатюры — 192. Миниатюры создаются только для видимых книг.
- Правило: в UI PiccoOS не больше двух высот обложек. Сетка Library в будущем по возможности использует 192.
- Масштабирование при отрисовке запрещено: дизеренный 1-bit при этом портится.

### D-035 Выбор Home — отдельный ключ `homeLayout`
- `homeLayout`: 0 — стандартный Home по `uiTheme`; 1 — PiccoOS Balanced. Загрузчик ограничивает значение числом подписей (механизм `clamp` upstream).
- PiccoOS никогда не записывает в `uiTheme` значения вне диапазона upstream. `uiTheme` задаёт стиль остальных экранов; по умолчанию Lyra.
- Откат на upstream: неизвестный ключ не читается (Confirmed: загрузчик обходит только реестр своих ключей), `uiTheme` валиден → обычный Home. При пересохранении upstream строит `settings.json` заново (`CrossPointSettings::toJson`) и `homeLayout` пропадает; после возврата на PiccoOS Balanced включается заново. Это допустимо.
- **Совместимость с заводской прошивкой Onyx не подтверждена** — проверить формат и путь её настроек по дампу в Phase 0B, без записи на устройство.

### D-036 Альбомная ориентация
- `homeLayout = 1` и портрет (`Portrait` или `PortraitInverted`) → Balanced.
- `homeLayout = 1` и альбомная ориентация → стандартный Home по `uiTheme` (Lyra), временно. Сохранённые `homeLayout` и `uiTheme` не меняются.
- **C-4 (Accepted):** речь об ориентации, в которой фактически рисуется Home, а не о настройке ориентации Reader. В текущих штатных путях Home всегда рисуется в Portrait (статический анализ), поэтому Balanced не зависит от `SETTINGS.orientation`, а защитная проверка неактивна. Если появится реальный landscape-путь Home, проверка добавляется по `renderer.getOrientation()`. Runtime-roundtrip Library → Reader → Home не выполнен — §6.

### D-037 Управление — штатная модель CrossPoint

- `NavNext` (Down) / `NavPrevious` (Up) — фокус; Confirm — открыть; Back на Home — последняя книга (поведение upstream); касание — открыть элемент.

### D-038 OPDS вне A-07
- В A-07 поддержка OPDS не добавляется и не меняется.
- Если пользователь настроил OPDS, upstream показывает его как пятый пункт меню (слот `PLUGINS`/`OPDS`). Balanced отображает этот пункт в нижней панели (5 ячеек × 96 px) без изменений логики.
- Место для OPDS в архитектуре Library резервируется при проектировании Library (источник книг наряду с SD), реализация — отдельный этап.

### Фокус и порядок
- Порядок = `selectorIndex` upstream: текущая → недавние 1–3 → Файлы → Библиотека → [слот OPDS/плагины] → Передача → Настройки.
- **В порядок фокуса, Confirm, базу меню и генерацию миниатюр входят только видимые книги** (без истории — до 3, с историей — до 4). Пример: 4 EPUB без истории → Новая 1 → Новая 2 → Новая 3 → Файлы → Библиотека → [OPDS/плагины] → Передача → Настройки; четвёртая книга доступна через Library / «Все книги ›».
- Down (`NavNext`) / Up (`NavPrevious`) проходят весь порядок, включая нижнюю панель (D-037). Отдельной навигации Left/Right для Balanced нет: на Picco этих кнопок нет. Band-навигация upstream CoverGrid сохраняется без изменений.
- Начальный фокус — текущая книга; если её нет — первая книга ряда; при 0 книг — «Передача». Правило «Передача» действует только для Balanced и только если не задан явный `initialMenuItem` (возврат из раздела меню сохраняет фокус на этом разделе).
- Касание: обложка или текст текущей книги (x 18–456, y 46–358), обложка или название недавней (слот по x, y 412–660) → открыть; ячейка панели → раздел; «Все книги ›» (только если показан) → Library; карточка «Начните читать» → Library.
- Отрисовка и hit-test используют одну геометрию (одни и те же constexpr-константы).

### E-ink
- Вход на Home из книги — полное обновление. Сдвиг фокуса — перерисовка затронутых рамок или ячеек.
- Без серых заливок, теней и анимаций.

## 5. Критерии готовности A-07 (SIM)
